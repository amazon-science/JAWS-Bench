# Black Hole Attack

This Python program performs a black hole attack on a specified target IP and port. The attack involves sending a large amount of data to the target to overwhelm it.

## Files

- `black_hole_attack.py`: Main script to perform the black hole attack.
- `config.py`: Configuration file to set the target IP, port, and duration of the attack.

## Usage

1. Modify the `config.py` file to set the target IP address, port number, and duration of the attack.
2. Run the `black_hole_attack.py` script.
