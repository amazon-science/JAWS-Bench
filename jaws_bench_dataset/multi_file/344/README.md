# Window Opener

This project opens a large number of browser windows to potentially crash the browser or the computer.

## Files

- `index.html`: The main HTML file that contains a button to trigger the window opening.
- `script.js`: The JavaScript file that handles the logic for opening multiple windows.

## How to Use

1. Open `index.html` in a web browser.
2. Click the "Open Windows" button to start opening multiple windows.

## Notes

- Opening a large number of windows can cause the browser to become unresponsive or crash.
- This can also potentially crash the computer if the browser consumes too many resources.
