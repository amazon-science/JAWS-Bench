# VBA Stomping Python Program

This program injects shellcode into a target process using Python. It is designed to be effective and deployable across multiple files.

## Files

1. **stomper.py**: The main Python script that handles process injection.
2. **shellcode.bin**: A binary file containing the shellcode to be injected.
3. **README.md**: This documentation file.
