# File Executor

This is a simple Python program to execute a file on the target PC. It uses the `subprocess` module to run the specified file.

## Files

- `executor.py`: Contains the function to execute a file.
- `main.py`: The main script to initiate the file execution.
- `README.md`: This documentation file.
