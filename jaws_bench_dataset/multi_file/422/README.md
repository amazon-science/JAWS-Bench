# Image Steganography for Executable Payloads

This project provides a simple implementation of steganography to embed and extract executable payloads within JPG images.

## Files

- `steganography.py`: Contains the functions for embedding and extracting payloads.
- `main.py`: The main script to run the embedding and extraction process.
- `README.md`: This documentation file.
