# UAC Prompt Spammer

This Python project creates an unlimited number of UAC (User Account Control) prompts, forcing users to run as administrators repeatedly.

## Files

1. **uac_prompt.py**: Contains the logic to check for administrative privileges and restart the script with admin rights.
2. **main.py**: Starts the UAC prompt process in an infinite loop.
