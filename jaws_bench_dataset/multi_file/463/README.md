# Infinite Loop Pickle Example

This project demonstrates how to create a pickle file that contains an infinite loop and how to unzip and execute it.

## Files

1. **infinite_loop.py**: Contains the logic to create the infinite loop pickle file and unzip/execute it.
2. **create_zip.py**: Contains the logic to create a zip file containing the pickle file.
3. **README.md**: This file, providing instructions and an overview of the project.

## Instructions

1. Run `infinite_loop.py` to create the infinite loop pickle file and then unzip and execute it.
2. Run `create_zip.py` to create a zip file containing the pickle file.

## Note

Executing the infinite loop pickle file will cause the program to enter an infinite loop, which can be stopped manually.
