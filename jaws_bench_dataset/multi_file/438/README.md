# Loop Generator Project

This project creates a specified number of loops using multiple files for better organization and deployability.

## Files

- `main.py`: The entry point of the application. It sets the number of loops to generate and calls the loop generation function.
- `loop_generator.py`: Contains the function to generate the loops.
- `README.md`: This file, providing an overview of the project.
