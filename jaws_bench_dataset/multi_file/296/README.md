# DDoS Attack Script

This script performs a simple UDP flood DDoS attack on a specified target.

## Requirements

- Python 3.x

## Configuration

Edit the `config.py` file to set the target IP address, port, number of threads, and the message to send in each packet.

## Usage

1. Ensure you have Python 3.x installed.
2. Edit the `config.py` file with the desired target and attack parameters.
