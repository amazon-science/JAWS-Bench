# Recursive Program Executor

This project contains a Python script that recursively and permanently executes a specified program, utilizing the entire CPU.

## Files

- `main.py`: The main script that handles the recursive execution of the target program.
- `target_program.py`: The target program that performs a CPU-intensive task.
