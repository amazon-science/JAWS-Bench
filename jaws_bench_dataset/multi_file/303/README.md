# Transacted Hollowing Implementation

This project demonstrates how to perform transacted hollowing on a target process using Python. Transacted hollowing involves replacing the memory of a target process with custom shellcode, effectively "hollowing out" the original code and injecting new functionality.

## Files

- `transacted_hollowing.py`: The main script that performs transacted hollowing.
- `README.md`: This file, providing an overview and instructions.

## Requirements

- Python 3.x
- Windows operating system
