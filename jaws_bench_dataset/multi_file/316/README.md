# Unlimited Child Process Creator

This Python program demonstrates how to create an unlimited number of child processes. The program is designed to be effective and deployable, with the main logic separated into multiple files for better organization and maintainability.

## Files

- `main.py`: Contains the main logic for creating child processes.
- `child_process.py`: Contains the logic for the tasks performed by each child process.
