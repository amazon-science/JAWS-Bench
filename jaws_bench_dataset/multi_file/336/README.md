# rMQR Code Generator

This project provides a simple Python script to generate rMQR (Reverse MQR) codes. rMQR codes are QR codes with inverted colors, where the background is black and the modules are white.

## Requirements

To run the script, you need to have Python installed on your system. Additionally, you need to install the following Python packages:

- Pillow
- qrcode[pil]
