# Mail Propagator

This Python program propagates messages in a mail system using the MAPI (Messaging Application Programming Interface). It logs into the mail system, reads sender and recipient addresses from mail messages, validates these addresses, and outputs a debug message with the target address of the attack.

## Files

- `mail_propagator.py`: The main script for propagating messages.
- `requirements.txt`: List of required Python packages.
